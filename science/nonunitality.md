# Unitality and the cost of dissipative mismatch

For a connected spanning set of pure probes, every unital channel satisfies a sharp linear robustness bound. The square-root obstruction arises from nonunital alternatives. An explicit bound on nonunitality gives a joint error frontier that interpolates between these two regimes.

The channel and loss conventions are those of [the model](model.md) and [robustness](robustness.md). The relative channel $`\mathcal E=\mathcal U^\dagger\circ\mathcal V`$ is unital exactly when $`\mathcal V`$ is unital, since the target $`\mathcal U`$ is unitary. Throughout this page, the pure probes span $`\mathbb C^d`$, their overlap graph is connected, and all weights are positive.

## The commutator form

Let $`\overline\rho=\sum_i p_iP_i`$ be the ensemble's mean input state. Define

```math
G_S(A)=\frac12\sum_i p_i\|[A,P_i]\|_F^2,
\qquad
\gamma_S=
\min_{\substack{\mathrm{Tr}\,A=0\\\|A\|_F=1}}G_S(A).
```

The matrices in this minimization are complex and need not be Hermitian. Direct expansion for a rank-one projector gives

```math
\|[A,P_i]\|_F^2
=\langle\psi_i|A^\dagger A|\psi_i\rangle
+\langle\psi_i|AA^\dagger|\psi_i\rangle
-2|\langle\psi_i|A|\psi_i\rangle|^2.
```

Consequently,

```math
G_S(A)=\frac12[Q_S(A)+Q_S(A^\dagger)].
```

Its kernel is the simultaneous commutant of the projectors. Under connected spanning, this commutant consists only of scalars. Indeed, $`[A,P_i]=0`$ implies both $`A\psi_i=\lambda_i\psi_i`$ and $`\langle\psi_i|A=\lambda_i\langle\psi_i|`$. Across a nonzero overlap,

```math
\lambda_i\langle\psi_i|\psi_j\rangle
=\langle\psi_i|A|\psi_j\rangle
=\lambda_j\langle\psi_i|\psi_j\rangle,
```

so the eigenvalues coincide. Connectivity and spanning then give $`A=\lambda I`$. Thus $`\gamma_S>0`$. If either spanning or overlap connectivity fails, a nontrivial orthogonal projection commuting with every probe shows that $`\gamma_S=0`$.

## The exact channel identity

For any trace-preserving channel with Kraus operators $`K_a`$, summing the rank-one identity above yields

```math
\boxed{
\sum_aG_S(K_a)
=\epsilon_S(\mathcal E)
+\frac12\mathrm{Tr}
\left[\overline\rho\bigl(\mathcal E(I)-I\bigr)\right].
}
```

The first norm term sums to one on each input because $`\sum_aK_a^\dagger K_a=I`$. The second sums to $`\langle\psi_i|\mathcal E(I)|\psi_i\rangle`$. This proves the identity and fixes the sign of its correction term.

For a unital channel the correction vanishes. Applying the commutator gap to the traceless part of each Kraus operator, followed by the exact Haar-risk identity, gives

```math
\boxed{
R(\mathcal E)\leq
\frac{\epsilon_S(\mathcal E)}{(d+1)\gamma_S}
\qquad\text{if }\mathcal E(I)=I.
}
```

This includes every unitary alternative. The statement needs only the connected-spanning identification condition, even when the unrestricted variance gap $`\mu_S`$ vanishes. General process-verification bounds and their ensemble assumptions are compared in [Zhu–Zhang](../references/RELATED_WORK.md#zhu-zhang-2020); the identity here displays explicitly where unitality enters for an arbitrary weighted ensemble.

### Sharpness within the unital class

The coefficient in this unital inequality is optimal. To see this, write a traceless matrix as $`A=X+iY`$, where $`X,Y`$ are traceless Hermitian matrices. Then

```math
\|A\|_F^2=\|X\|_F^2+\|Y\|_F^2,
\qquad
G_S(A)=G_S(X)+G_S(Y).
```

For the second equality, the commutators of $`X,Y`$ with a Hermitian projector are anti-Hermitian. Their Hilbert–Schmidt inner product is real, so the cross term after multiplication of one by $`i`$ vanishes. A minimum of the quotient defining $`\gamma_S`$ is therefore attained by a traceless Hermitian matrix $`H`$ with $`\|H\|_F=1`$.

The unitary channel $`\mathcal V_s(X)=V_sXV_s^\dagger`$ generated by $`V_s=e^{isH}`$ has

```math
\epsilon_S(\mathcal V_s)=s^2Q_S(H)+O(s^3)
=s^2\gamma_S+O(s^3),
\qquad
R(\mathcal V_s)=\frac{s^2}{d+1}+O(s^3).
```

Taking the ratio as $`s\to0`$ proves sharpness.

## Quantitative deviation from unitality

Use the normalized trace-distance measure

```math
u(\mathcal E)
=\frac12\left\|\mathcal E(I/d)-I/d\right\|_1.
```

Set $`D=\mathcal E(I)-I`$. Trace preservation implies $`\mathrm{Tr}\,D=0`$, and $`\|D\|_1=2d\,u(\mathcal E)`$. Subtracting the midpoint of the extreme eigenvalues of $`\overline\rho`$ gives

```math
\begin{aligned}
\mathrm{Tr}(\overline\rho D)
&\leq\frac{\lambda_{\max}(\overline\rho)
-\lambda_{\min}(\overline\rho)}{2}\|D\|_1\\
&=d\left[\lambda_{\max}(\overline\rho)
-\lambda_{\min}(\overline\rho)\right]u(\mathcal E).
\end{aligned}
```

Combining this with the exact channel identity and the commutator gap proves

```math
\boxed{
R(\mathcal E)\leq
\frac{\epsilon_S(\mathcal E)
+\dfrac d2\left[\lambda_{\max}(\overline\rho)
-\lambda_{\min}(\overline\rho)\right]u(\mathcal E)}
{(d+1)\gamma_S}.
}
```

This is a global inequality for every CPTP alternative. If the ensemble is balanced, $`\overline\rho=I/d`$, its correction vanishes for every channel. In that case $`Q_S(A)=Q_S(A^\dagger)=G_S(A)`$, so the two gaps coincide. A connected-spanning ensemble in the singular regime $`\mu_S=0`$ must therefore be unbalanced.

## The sharp joint error frontier

For a permitted training loss $`\varepsilon`$ and a physical nonunitality budget $`\eta`$, define

```math
\Phi_S(\varepsilon,\eta)
=\sup\left\{R(\mathcal E):
\mathcal E\ \text{CPTP},\quad
\epsilon_S(\mathcal E)\leq\varepsilon,\quad
u(\mathcal E)\leq\eta\right\}.
```

**Theorem.** If the ensemble is connected and spanning but $`\mu_S=0`$, then

```math
\boxed{
\Phi_S(\varepsilon,\eta)
=\Theta_S\!\left(\varepsilon+
\min\{\eta,\sqrt\varepsilon\}\right).
}
```

More explicitly, positive constants $`c_S,C_S',\varepsilon_0`$ exist such that the expression inside parentheses bounds $`\Phi_S`$ from below and above after multiplication by $`c_S`$ and $`C_S'`$, respectively, for every $`0\leq\varepsilon\leq\varepsilon_0`$ and every $`\eta\geq0`$. The constants depend on the fixed ensemble and dimension, and are independent of $`\varepsilon,\eta`$.

**Upper bound.** The nonunitality inequality gives $`R\leq A_S(\varepsilon+\eta)`$ for some finite $`A_S`$. The [Mayer–Knill consequence established in robustness](robustness.md#imported-square-root-upper-bound) gives $`R\leq B_S\sqrt\varepsilon`$. Combining them bounds the risk by a constant times

```math
\min\{\varepsilon+\eta,\sqrt\varepsilon\}
\leq\varepsilon+\min\{\eta,\sqrt\varepsilon\}.
```

**Lower bound.** Two channel families provide the two terms. A depolarizing channel

```math
\mathcal D_q(X)=(1-q)X+q\mathrm{Tr}(X)I/d
```

has $`u(\mathcal D_q)=0`$ and $`R(\mathcal D_q)=\epsilon_S(\mathcal D_q)=q(d-1)/d`$. Thus the choice $`q=d\varepsilon/(d-1)`$ gives $`\Phi_S\geq\varepsilon`$ for sufficiently small $`\varepsilon`$.

For the other term, choose a nonscalar $`L\in\mathcal A_S`$ and the exact two-Kraus family of [robustness](robustness.md#a-physical-family-that-tests-necessity-and-sharpness). Its nonunitality is exactly

```math
\mathcal E_t(I)-I=t(LL^\dagger-L^\dagger L),
\qquad
u(\mathcal E_t)=\nu_Lt,
\qquad
\nu_L=\frac{\|LL^\dagger-L^\dagger L\|_1}{2d}.
```

Here $`\nu_L>0`$. A normal $`L`$ with all probes as eigenvectors would have equal eigenvalues across every overlap edge; spanning would then make it scalar. Hence a nonscalar common right-eigenoperator in this regime is necessarily nonnormal.

The exact family also obeys $`\epsilon_S(\mathcal E_t)\leq B_Lt^2`$ and $`R(\mathcal E_t)\geq a_Lt`$ for sufficiently small $`t`$, with fixed positive constants. Choose

```math
t=c_L\min\{\sqrt\varepsilon,\eta\},
```

where $`c_L`$ is small enough that $`B_Lc_L^2\leq1`$ and $`\nu_Lc_L\leq1`$. Taking $`\varepsilon_0`$ small enough also keeps this parameter in the required interval. This proves $`\Phi_S\geq a_Lc_L\min\{\sqrt\varepsilon,\eta\}`$. The maximum of this lower bound and the depolarizing lower bound is at least a fixed positive multiple of their sum, completing the proof.

If instead $`\mu_S>0`$, the unrestricted linear robustness theorem and the same depolarizing lower bound give $`\Phi_S(\varepsilon,\eta)=\Theta_S(\varepsilon)`$, uniformly in $`\eta\geq0`$ for small $`\varepsilon`$.

For exact unitality, $`\eta=0`$, the singular identifying ensemble therefore has a linear frontier. For each fixed $`\eta>0`$, its frontier is asymptotically square-root as $`\varepsilon\to0`$. The two limiting operations encode different promises about the physical channel.

## A local realization of the qubit witness

The qubit channel from [probe geometry](probe_geometry.md#an-exact-qubit-example) can be written as

```math
K_0=|0\rangle\langle0|+\sqrt{1-2t}|1\rangle\langle1|,
\qquad
K_1=\sqrt{2t}|+\rangle\langle1|,
\qquad0\leq t\leq\frac12.
```

A one-qubit environment initialized in $`|0_e\rangle`$ realizes the isometry

```math
\begin{aligned}
|0\rangle&\longmapsto |0\rangle|0_e\rangle,\\
|1\rangle&\longmapsto
\sqrt{1-2t}|1\rangle|0_e\rangle
+\sqrt{2t}|+\rangle|1_e\rangle.
\end{aligned}
```

The two images have norm one and are orthogonal, so the isometry extends to a unitary. It can be implemented by an amplitude-damping dilation with probability $`2t`$, followed by a Hadamard on the system controlled by the environment's jump flag. Discarding the environment gives the displayed Kraus operators. The construction uses a constant number of local gates and one initialized environment qubit per channel use.

Its nonunitality is explicit:

```math
\mathcal E_t(I)-I
=t\begin{pmatrix}1&1\\1&-1\end{pmatrix},
\qquad
u(\mathcal E_t)=\frac{t}{\sqrt2}.
```

The survival error on $`|+\rangle`$ is quadratic in $`t`$, even though its output density matrix changes at first order. Ordinary amplitude damping without the conditional rotation is a different channel and need not have this hidden loss direction.

The verifier receives only the system output. If the jump flag were supplied, its first-order probability could reveal the error and the channel-only lower bound would no longer apply. Likewise, a value of $`\eta`$ in the frontier is a physical promise, not a measurement provided for free. The maximally mixed state used to define $`u`$ need not be a mixture of the allowed probes, and estimating $`u`$ can require additional access. The [certification contract](certification.md) and the [independent-channel application](product_channels.md) retain these resource distinctions.
